updated: 2026-08-23

- (event) Sources confirmed: prd.md + addendum.md (prd-conchi-2026-08-20). Coaching path selected. Extracting PRD via subagent.
- (decision) Visual register: C — character in font and data presentation, modern shell. Not full costume.
- (decision) Design direction: Folio B — Typewriter Amber. Palette: bg #18140f, accent #c8922a, text #fdfaf4, muted #b09870.
- (decision) Typography: Special Elite (hero totals only) / Courier Prime (all data in lists) / System UI Roboto (all chrome — buttons, nav, labels).
- (asset) Conchi pixel art avatar confirmed — 3 states: idle (sitting at desk with book), processing (calculator "CONCHI" + writing), error (hands on head, glitch RGB artifacts). Assets provided by Marc, need palette recolor once final tokens locked.
- (asset) App icon confirmed — amber rounded square (#c8922a approx), dark accountant lady silhouette. Already aligned with Folio palette.
- (decision) Bottom nav structure: Home | FAB | Analytics. Settings lives as gear icon in header top-right.
- (decision) Tab icons: Home = house, Analytics = bar chart. FAB = center amber circle with +.
- (decision) Tab labels: icon + text label on each tab.
- (decision) Active tab state: amber icon + amber label (#c8922a). Inactive: muted tan (#b09870).
- (note) Design direction mockups (rounds 1–3) are visual-only proofs for palette/font/feel — not screen specs. Nav content, data layout, icon choices, and component anatomy are being defined in this coaching session.
- (decision) Bottom nav style: notched/cradle pattern — bar has smooth curved cutout at center top, FAB elevated inside the cutout. FAB is a circle (not rounded square). Amber (#c8922a) FAB.
- (decision) Home header: NO app name shown. Total amount (Special Elite, large) + period sublabel below (System UI, small, muted). Period is user-configured in Settings. Sublabel: "mes actual" mode → shows actual month name + year (e.g. "agost 2026"); other modes → show period label ("últims 30 dies", "últims 7 dies", "setmana actual"). Gear icon (⚙) top-right navigates to Settings.
- (decision) Home list + header total are both filtered by the selected period. Entries outside the period are not shown. Month section headers still group visible entries by calendar month.
- (decision) Language: Catalan by default. English selectable in Settings. No Spanish anywhere in the app. All UI copy must be Catalan-first.
- (decision) Home list: newest-first, grouped by month. Month section header shows month name (left) + month total (right, amber).
- (decision) Expense row anatomy: left side = Category (primary, Courier Prime) + Subcategory (secondary, smaller, muted); right side = Amount (primary, Courier Prime) + Date (secondary, smaller, muted).
- (decision) Row expand: accordion in-place on tap. Expanded area shows: Description, Context, attachment filename (if present). Tap again to collapse.
- (decision) Row indicators: small amber icons below the date (right side) when present — paperclip for attachment, tag for context. No icon shown when absent (no empty space reserved).
- (decision) Confirmation Card anatomy (top→bottom): Amount (Special Elite, large, EDITABLE — tap to correct extraction) → Category+Subcategory side-by-side drum pickers → Date (editable, defaults today) → Description (editable inline) → Context drum roll picker (only if contexts exist) → Attachment indicator + open/preview (only if file present) → Conchi voice quote (italic Courier Prime) → Discard | Accept buttons.
- (decision) FAB radial fan: upward arc, 3 options — ✏️ Escriure / 📷 Càmera / 📄 PDF. Labels in Catalan above each mini-button.
- (decision) Swipe-to-reveal (FR-12): colored action buttons revealed behind the row. Show = amber (only when attachment exists), Edit = muted/neutral, Delete = dark red. Symmetric — same on both swipe directions.
- (decision) Delete confirmation: inline on the row — row turns red, shows "Segur?" + Eliminar button. No modal.
- (decision) Analytics screen: swipeable chart area — swipe left/right between chart types (donut/pie and bar chart at minimum). Active chart type persists per user preference. Filters: date range / category / subcategory / context — horizontal scrollable amber chips. Chart top ~40% screen, filtered expense list scrolls below. Same row anatomy as home. Small page-dot indicator below chart shows current chart type position.
- (decision) Settings screen: grouped sections — CONNEXIÓ (URL webhook, endpoint SSE) / VISUALITZACIÓ (periode per defecte, idioma, tema) / CONTEXTOS (navigates to separate context manager screen) / SOBRE (versió).
- (decision) Context manager: separate full screen navigated from Settings. List of contexts with name + edit + delete per row. Add new context from this screen. This resolves OQ-14 (Settings is a confirmed context creation surface).
- (decision) Persistent Conchi floating bubble: top-right of the screen, always visible, overlays content. Three states driven by pixel art assets: idle (default/waiting), working (during Phase 2 processing), error (error occurred → auto-reverts to idle after 10 seconds). Tapping the bubble opens Settings. No separate gear icon anywhere.
- (decision) Two-phase loading (resolves OQ-11): Phase 1 (Enviant — HTTP in-flight) → FAB shows inline spinner, brief overlay or FAB state change. Phase 2 (Processant — n8n working, waiting for SSE) → app is fully browsable, Conchi bubble switches to working state. Confirmation Card appears on SSE response. Error state: Conchi bubble switches to error, auto-revert after 10s.
- (decision) Home header final layout: total amount left (Special Elite, large) + period label below (Catalan) / Conchi bubble top-right (tap → Settings). No app name, no gear icon.
- (event) DESIGN.md and EXPERIENCE.md written and finalized. UX coaching session complete.
