# Conchi

Conchi is a bare React Native mobile app — the mobile interface to Conchita, a
self-hosted AI accounting agent (n8n + PostgreSQL + Google Drive).

This documentation site is a placeholder scaffolded in Story 1.1 (Project Skeleton &
CI/CD). Content is filled in as later stories land.

The component library lives in [Storybook](https://markuson.github.io/conchi/storybook/).
